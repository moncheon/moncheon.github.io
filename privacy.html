개인정보처리방침

작성일: 2026년 9월 30일 · 적용 범위: 이 홈페이지의 무료 호숫가 산책 웹게임

runmoon(런문)의 이 웹게임은 회원가입, 결제, 광고, 방문 분석 도구를 사용하지 않습니다. 게임 기록은 현재 열린 페이지의 메모리에만 있고, 새로고침하거나 페이지를 닫으면 사라집니다.

1. 웹게임에서 처리하는 정보

캐릭터 선택, 위치, 걸음 수와 꽃의 위치는 브라우저 안에서 게임을 표현하기 위해서만 사용됩니다. 운영자 서버로 전송하거나 저장하지 않습니다. 이 게임은 쿠키, localStorage, sessionStorage를 사용하지 않습니다. 이름, 이메일, 전화번호 등을 입력하는 양식도 없습니다.

2. 웹사이트 호스팅

이 웹사이트는 GitHub Pages로 제공됩니다. 페이지를 불러오는 과정에서 GitHub는 보안 등의 목적으로 방문자의 IP 주소 등 접속 정보를 처리할 수 있습니다. 이는 게임의 방문 분석 기능과 별개이며, GitHub의 처리 및 보관 기준은 GitHub 개인정보처리방침과 GitHub Pages 데이터 수집 안내에서 확인할 수 있습니다.

3. 외부 서비스와 제공 범위

이 홈페이지의 웹게임에는 외부 광고·분석 SDK, 소셜 로그인, 외부 글꼴 및 외부 콘텐츠 임베드가 없습니다. 운영자는 이 게임의 플레이 정보를 제3자에게 제공하거나 판매하지 않습니다. 외부 링크를 직접 누르면 해당 웹사이트의 방침이 적용됩니다.

이 안내는 루트 홈페이지의 산책 게임에 한정됩니다. 별도 경로에서 제공되는 다른 프로젝트나 향후 출시하는 앱에는 그 서비스의 기능에 맞는 별도 안내가 필요합니다.

4. 이용자의 선택

‘다시 산책’을 누르면 현재 게임이 초기화됩니다. 페이지를 새로고침하거나 닫아도 게임 기록이 사라집니다. 가입 계정이나 운영자에게 전송된 플레이 기록이 없으므로 이 웹게임에는 계정 삭제 절차가 없습니다.

5. 운영자 및 문의 창구

서비스명: runmoon(런문). 현재 사업자등록 준비 중이며, 운영자 상세 정보와 개인정보 문의 창구는 확정 후 홈페이지 하단과 이 페이지에 게시합니다. 현재 이 사이트는 문의 내용을 접수하는 양식을 제공하지 않습니다.

6. 변경 안내

회원가입, 판매, 문의 접수 또는 분석 기능 등 개인정보 처리 방식이 달라지는 기능을 도입하기 전에 이 안내를 해당 기능에 맞게 갱신합니다. 변경 내용과 적용일은 이 페이지에 게시합니다.
